# KONSTANTIN / ORBIS — DCC SCULPTURAL SOURCE 01

**Status: isolated Blender source reconstruction, NOT approved for animation or production.**

This experiment responds to six previous failed browser/procedural approximations (v01–v06) and one failed four-sheet Blender geometry experiment (v07). The approved target is the original Orbis v2 reconstruction crop and motion sheet provided by the project owner. The source reference image is **not stored** in this public experimental branch, mapped onto any geometry, distorted at runtime or used as a background/texture.

## Artistic reconstruction method

- **Nine** distinct authored lofted 3D surfaces, each defined by two independent, manually controlled boundary splines with per-point 3D depth (not a single path + width ribbon).
- Physically real, closed outer sphere with controlled grazing-angle optical material.
- Spatially coherent additional sub-membranes: high background enclosure, darker folding chamber, burgundy interior volume, separate slim burgundy signature flow, lower ivory return.
- Gentle material striation follows existing geometry and stays subordinate. No 210 overly bright wireframe filaments.
- Separate stills in dark and light studio setups; actual Blender scene `.blend` generated by script.
- **No automatic sine-wave movement**. No animation at this stage. Future poses must deform the same physical meshes only after dark and light static renders meet the accepted art direction.

## Reproduction

```bash
blender -b --threads 4 --python scene.py -- --out output --theme dark --mode clay --size 640 --samples 20
blender -b --threads 4 --python scene.py -- --out output --theme dark --mode beauty --size 640 --samples 84
blender -b --threads 4 --python scene.py -- --out output --theme light --mode beauty --size 640 --samples 84
```

Actual run is on GitHub Actions public runner: `.github/workflows/orbis-dcc-sculpt-20261127.yml`. Produces a retained artifact with three editable Blender source files and three full source-camera PNG stills. Diagnostics are published to `docs/renders/orbis-sculpt-20261127/` on public main after successful render.

## Acceptance threshold

A green CI job proves scene construction and rendering, **not** resemblance to the approved reference. Review:
1. Full-layer clay silhouette and occlusion against the reference at equal scale.
2. Broad translucent ivory membranes with *visible folds and internal layering*, not disconnected cut-paper strips or a technical mesh.
3. Burgundy current must be narrow, directed, integrated with surrounding form; avoid opaque red leaves and eyelike shapes.
4. Dark smoked glass with selective reflections instead of uniform beige/opaque coating or rectangular highlights.
5. The same geometry must work in the **light** theme with different studio lighting; do not merely recolor the UI.
6. No raster warping / viewport light filters standing in for geometry.

Only if the STILL gate passes should an explicitly crafted sculptural pose rig and slow Cycles-rendered motion sequence be developed. Do not fork another iteration just to add shader patches. Keep the parallel Ribbon experiment untouched.
